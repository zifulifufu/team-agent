# 把「读图里的文字」接进程序（2026-09-27）

起因：用户问「有没有本机免费高效的识图软件」，确认了 macOS 自带的 Vision 可用之后说
**「如果自带的能够识别就接本地的就可以了」**。

## 一、先说的那条界线：它不是「看图」

程序里「谁能看图」只有一条判据 —— `vision._can_see`（带 `multimodal` **且** `purpose_of(...)
== "chat"`），`vision_cloud` 是唯一的云端闸门。**本地 OCR 没有被塞进这条判据，也不许塞进去。**

理由不是洁癖。有人只做了一次文字识别却被告知「这就是图上的内容」，他会拿图表的坐标轴标签去讲那张图表，
并且相信自己看懂了。所以：

- 它是**另一件事**：一个内置工具 `read_image_text`，一条独立的「能不能用」判据；
- 它给的东西**永远带着一句说明**，而且只有一条出口 `localocr.render()` —— **模块不提供裸文本接口，
  这是有意的**；
- 附件那条路在看不了图时**两半都给**：为什么没有人看过（`vision.reason_missing`）+ 图上的文字。
  只给后半句，读的人会把它当描述。

## 二、接在哪三处

| 位置 | 行为 |
|---|---|
| `toolhub` 新工具 `read_image_text` | 成员显式调用。`path`/`paths`(≤12)/`at_seconds`（视频取一帧） |
| `orchestrator._visual_text` 回退 | 看不了图且没有描述时，先读文字；读到了就连同原因一起注入 |
| `/api/capabilities` + 设置页 | `text_from_image: {ready, reason}`；「看图用哪个模型」那一行现在会说"图上的文字照样读得出来" |

`localocr.py` 照 `ffmpeg.py` 的形状写（叶子模块、`path()`、`available() -> (能用/不能用)`）。
程序**按它自己的回答认，不按名字认**：跑一次 `ocr --languages`，认得出 `accurate` 才算数 ——
`bindirs.tool("ocr")` 会把任何叫 `ocr` 的可执行文件找出来，而一个别的 `ocr` 拿到 `--json` 之后
输出的东西会被解析成「这张图没有文字」，那是**穿着正确答案外衣的错误答案**。

## 三、`risk` 为什么是 `read`（按先例推，不按直觉）

技能里写着「跑外部程序的一律 `exec`」，但**这个仓库实际编码的是效果，不是机制**：

- `review_audio` = **`read`**，而它要跑转写器；
- `review_picture` = **`read`**，而它会把图片字节发给第三方模型；
- `render_document` = `write`，而它跑 `soffice` + `pdftoppm`。

而 OCR 什么都不改、什么都不发，唯一的动作是跑本机识别器，路径参数还被锁在本群工作目录内
（`assemble._local`）。标 `exec` 的代价是实打实的：**每次调用弹审批**，而且**网络触发的只读轮次
拿不到它**（`read_only_tools` 只放行 `risk == "read"`）—— 一张从聊天通道进来的截图就永远读不了。

## 四、实测

| 事项 | 结果 |
|---|---|
| 一张 1080×1920 | **≈80 ms**（24 张 1.9 秒） |
| 从成片抽帧读字幕 | 9/9 与 `.srt` 逐字一致 |
| 最小可读字号 | 汉字高 **≈11 px 能读、≈8 px 读不出** → 别先缩图 |
| 语言 | accurate 30 种（含 zh-Hans/zh-Hant/yue）；⚠️ **fast 只有 6 种拉丁语、完全没有中文** |
| 低置信行 | 代码画的装饰元素读成 `Lala`（conf 0.30）；正常字幕 0.50–1.00 → 阈值取 0.35，**且被丢的行要数出来说** |

## 五、知道的边界（写进 README 的那几条）

- **不理解画面**：`--classify`（本机图像分类）只给粗名词，实测 `手术室门`→door ✓、`ICU 床`→bed ✓、
  `两只手相握`→bedding ✗。要判断「版式/配色/像不像」仍然只能交给能看图的模型。
- 它**不替代**视觉模型：图上没有文字时答案是「没有读出文字」，那不是失败，但也不是描述。
- 程序**没随仓库发布**：本机在 `~/.local/bin/ocr`（源码与做法在 `~/.local/opt/macos-ocr/`）。
  缺它时 `available()` 给的是**编译它的位置**，不是一句「没有」。
