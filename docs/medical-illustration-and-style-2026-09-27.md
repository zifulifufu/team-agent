# 片子里的图为什么不像样：诊断 + 医学绘图工具调研（2026-09-27）

用户反馈三条：① 配的图和他提供的素材不是一个风格；② 微导管画得不对；③ 支架没有在动态里显示出来；
并问：GitHub 上有没有更专业的医学绘图工具。

结论先写：**①②③ 是真的，而且不是"调一调参数"能解决的**；**GitHub 上没有能直接用的介入器械绘图库**
（原因见第三节）。真正可行的路是「扩本机绘图内核 + 定一套片子规范」，详见第四节。

⚠️ 本文件的视觉判断**全部来自量化数据与代码**。写这份时两条云端视觉通道都在限流
（metachat 429 / moonshot 429），我**没能亲眼看到这些图**，凡属"看起来"的结论一律标注为推测。

---

## 一、量化诊断：两套东西根本不是一个语言

用 `style_probe.py`（全分辨率边框取底色，不在缩略图上量）读了两组：

| 组 | 画幅 | 底色 | 颜色数 | flat（前 8 色覆盖率） | 判定 |
|---|---|---|---|---|---|
| **用户提供的素材**（`uploads/`，8 张） | 3088×2316 / 1707×1280 / 1280×960，**全是 4:3** | `#EAF0EC` `#E7ECE6` `#C7C3BA` `#85827D` `#EEEEEE`（**浅底，每张不同**） | 39k–100k | **0.028–0.067** | **照片 / 真实影像类** |
| **片子里的机制帧**（`anim/`） | 1920×1080（16:9） | `#0C1016`（近黑，统一） | ~490–650 | **0.95–0.97** | 深底扁平矢量 |
| **片子里的配图**（`figures/`） | **1080×1920 与 1920×1080 混用** | ⚠️ **`#0C1016` 与 `#0B1422` 两种** | 700–21500 | 0.71–0.98 | 矢量 + 少数文献图 |

三个可以直接说给用户的结论：

1. **素材是浅底连续色调的照片类，片子是深底扁平矢量** —— 这两者没有"同一种风格"可言。
   一条片子把照片和矢量混着放，读起来就是「两段拼的」，跟素材像不像无关，**是片子自己内部就不统一**。
2. **片子内部也不统一**：底色有**两种**（`#0C1016` / `#0B1422`，差 4/255），画幅**混用**
   （1080×1920 与 1920×1080 同片并存）。
   ⚠️ 这两条**不是本轮的新病** —— 它们是上一轮视觉规范工作（`app/visual.py`）里就明确记下的
   「已知未做」项：程序自画的卡片/动画仍用 `figure.DRAWING_BG`(`#0B1422`)，装框底用 `figure.INK`(`#0C1016`)。
   写在这里，是因为它们是"看起来乱"的**直接来源**，而不是因为这一轮才出现。
3. **用户的素材很可能根本没进片**（flat 0.03–0.07 的照片，与片子里 0.95 的矢量对不上；
   `figures/` 里那两张 flat 0.71–0.73、颜色数 4k–21k 的才是外来图）。

## 二、微导管画得不对、支架不在动态里 —— 是能力边界，不是执行失误

`make_animation` 只有**五个固定预设**（`backend/app/animate.py` 的 `ANIMATION_INFO`）：

```
blood_flow        血流沿血管流动
aneurysm_grow     管壁薄弱处鼓出成囊
coil_fill         弹簧圈一圈圈填进瘤腔
catheter_advance  微导管沿血管前进、拐进瘤腔
contrast_fill     造影剂充盈显影
```

于是：

- **支架、血流导向装置、球囊、微导丝 —— 一个都没有**。用户要的"支架在动态里显示出来"，
  在当前内核里**画不出来**（成员只能改标题，而工具说明里已明令禁止改名冒充）。
- **微导管的形态是代码里的一条曲线**，不是按真实器械画的：真实微导管是**细径、头端有塑形弯
  （如 45°/90°/J 形）、带铂金显影标记**；当前预设画的是等宽光滑管。
  （"画得不对"的具体形态需以真帧复核，我这里只能从代码判断它有塑形与显影标记两处缺失。）
- 已发生的连带损失（昨夜实测）：镜 2 要求"导管尖进瘤腔"，而 `catheter_advance` 画不出来 →
  成员**打回重画了三轮**，最后被迫把这一镜改成 `blood_flow`，画面与旁白「送一根细管子」脱节。

## 三、GitHub 调研：没有现成的介入器械绘图库

搜了四轮（医学图标库 / 血管内器械 / 可脚本化绘图库）。候选与结论：

| 候选 | 许可 | 规模 | 能不能解决器械问题 |
|---|---|---|---|
| [Bioicons](https://github.com/duerrsimon/bioicons) | MIT | 4000+ SVG | ❌ 细胞/分子/实验室/器官图标，**无血管内器械** |
| [Health Icons](https://github.com/resolvetosavelives/healthicons) | CC0 | 1100+ | ❌ 是 UI 图标（描边/填充两风格），非解剖插画 |
| SciDraw | CC 系列 | 生物医学 | ❌ 同上，偏生物 |
| [NeuroSVG](https://github.com/MartinPyka/NeuroSVG) / [open-pain-illustration](https://github.com/DigitalHealthZurich/open-pain-illustration) | CC-BY | 少量 | ❌ 神经解剖/疼痛标注，非介入 |
| Servier Medical Art | CC-BY 4.0 | 3000+ 插画 | ⚠️ 最可能含**心血管解剖底图**；器械仍需自绘，**需署名** |
| [drawsvg](https://github.com/drummonds/drawsvg) | MIT | 694★，895k 下载/月 | ⚙️ **绘图引擎**（纯 Python、无依赖、可导 PNG/MP4/GIF）——不是素材库 |
| svgwrite | MIT | 2.4M 下载/月 | ⚙️ 同上，只能生成 SVG 文本 |

**为什么没有**：介入器械（Pipeline / Neuroform Atlas / Excelsior SL-10 之类）的示意图在文献与教材里
几乎都标着 `Reproduced with permission of Medtronic` / `Credit: Stryker, used with permission` ——
它们**是厂商版权资产或委托医学插画师绘制**，不是开源素材。想拿"专业器械插画"只有两条合法路：
拿厂商官方图（授权）或自己画。

## 四、建议：扩内核 + 定规范（两条一起做才有用）

**A. 扩 `figure.py` 的器械内核**（直接解决 ②③）

按真实器械的几何特征加绘制器与预设：

| 要加的 | 关键几何（决定"像不像"） |
|---|---|
| 支架（编织网筒） | 两组交叉螺旋线构成菱形网孔；**网孔密度与金属覆盖率**；贴壁 vs 未贴壁（内漏） |
| 血流导向装置 | 比支架**更密的编织网**（真实 PED 为 48 根钴铬丝 + 12 根铂钨显影丝，可据此定网孔与显影点） |
| 微导管 | **细径**（与血管直径比例）+ **头端塑形弯** + **铂金显影标记环** + 可推入/回撤 |
| 微导丝 / 球囊 / 中间导管 | 细线 + 头端 J 形；球囊为可膨胀椭圆；三轴系统层次 |

这些全部是几何图元，用现在这套 Pillow 逐帧绘制就能做，**而且天然能逐帧动**（要"支架在动态里显示"就必须走这条路）。
参考依据应来自器械的**结构参数**（编织丝数、内径、网孔）而不是凭空画——这一点必须由医学成员对照真实器械审图。

**B. 定一套"片子规范"并把已有图统一过来**（直接解决 ①）

- **一个底色**（从 `#0C1016` / `#0B1422` 里定一个，另一处硬编码的也要改）；
- **一套调色板**（血管、瘤囊、微导管蓝、血流青、弹簧圈白金——按"出现在多少张图里"投票取，不按像素多少）；
- **一种画幅**（成片 16:9 就全部按 16:9 出）；
- **一条标注带**（标题/来源/免责只出现**一次**——当前成片有叠印，见昨夜审计）；
- 用户的**照片类素材不重画**，走"装框"（统一边框、标题、来源行），这是唯一诚实的处理方式。

**C. 补充素材（可选）**：Servier Medical Art 的心血管解剖底图（CC-BY，需署名）+ drawsvg 作为矢量绘图后端。
⚠️ 这是锦上添花，**不解决器械问题**。

## 五、我没能做的

- **本文件没有"看过图"的判断**：两条视觉通道都在限流，`review_picture` 只能由群成员在群里调用。
  用户素材的**具体内容**（是 DSA 造影截图、术中照片，还是教材插画）我只能从量化特征判定为"照片类"，
  内容未核实 —— 这一点请用户一句话确认，它决定了素材该走"装框"还是"可重画"。
- 器械绘制需要**真实器械的结构参考**；本机成员没有联网搜图能力（只有文献检索、文档自带图、看图复核），
  所以"补参考图"这一步需要用户提供或指定来源。
