# 把 PSD 素材变成一个会自我升级的「神经介入绘图专家」——可行性与方案

2026-09-27。用户诉求：**「我这边有很多医学绘图的 psd 格式的素材，是否能够把这些素材充分学习然后做成
神经介入绘图专家？神经介入绘图专家可以随着我的资料库里增加，然后继续升级自己」**

结论：**能做**，但"学习"这三个字要拆开说 —— PSD 能给出的是**可量化的规范 + 可复用的元件**，
不是"手艺"。下面先讲能学到什么、学不到什么，再讲落成什么形态、怎么升级。

## 1. PSD 能"学"到什么（这是它比 PNG 强的地方）

PSD 是**分层**的，而 PNG 是压平的结果。这一条差别决定了整套方案可不可行：

| 可提取 | 怎么用 | 为什么 PSD 比 PNG 强 |
|---|---|---|
| **图层树** | 分层习惯（底 / 解剖 / 器械 / 标注 / 文字）→ 规范 | PNG 里这些都糊在一起，看不出画家的工序 |
| **每层的填充与描边色** | **精确色板**（血管红 / 微导管蓝 / 弹簧圈白金…） | PNG 的颜色被抗锯齿和混合污染；PSD 里是**原始色值** |
| **文字图层** | 标注用语、字体、字号 → 术语表 + 排版惯例 | PNG 只能靠 OCR 猜，PSD 是文本本身 |
| **矢量形状 / 蒙版** | 可导出 **SVG 元件** | PNG 只能切位图，放大就糊 |
| **图层名** | 术语（「微导管」「瘤颈」「支架」）→ 术语表 | 名字就是作者自己的用词 |
| **图层的开关组合** | 同一文件常放着「未治疗 / 弹簧圈 / 支架」几个变体 → **术式变体的画法差异** | PNG 一张只能看到一个状态 |
| **画布尺寸/分辨率** | 常用画幅 | — |

**色板与术语这两项，能直接解决之前那个"配图和素材不是一个风格"的病**：现在片子的色板是程序
自己定的（`#0C1016` 底 + 一套通用色），有了你的 PSD 色板，才算"像你画的那套"。

## 2. PSD 学**不到**什么（不吹）

- **手艺**：笔触节奏、构图审美、哪根血管该收窄、瘤颈该画多宽 —— 这些不在文件里，给不出。
- **位图图层的质感**：如果素材里有关键部分是手绘位图或 3D 渲染，只能**原样复用**，无法参数化。
- **"看一眼就会画"**：本机没有 SDXL + ControlNet + IP-Adapter（上次盘点确认过），
  所以**不能**用扩散模型把这些素材"学成风格再生成新图"。硬要生成，就是解剖幻觉 —— 医学内容不能这么办。

## 3. 落成什么形态：三件套 + 一个摄取脚本

```
① 专家（EXPERT_PRESETS 里加一条）
   「神经介入绘图专家」：职责 = 出图前定规范、出图后过验收；明确写清它不做什么（不凭记忆画解剖）

② 技能包  ~/.team-agent/skills/neuro-illustration/
   SKILL.md          绘图规范（画幅 / 色板 / 分层 / 线宽 / 标注位置 / 术语口径）
   references/       色板.json · 术语表.md · 素材索引.md（每个 PSD 的元数据）
   assets/           从 PSD 导出的可复用元件（SVG 优先，位图其次）

③ 资料库（library）
   素材原件与合成预览进知识库，成员用 library_search / list_figures 取用

④ scripts/ingest-illustrations.py
   扫素材目录 → 解析每个 PSD → 合并进 ② 的知识文件 → 输出版本号与差异报告
```

**产出图的三条路**（按"像不像你的素材"排）：

| 路 | 做法 | 代价 |
|---|---|---|
| **A 元件复用**（推荐先做） | 把 PSD 图层导出成透明元件，按规范拼装到镜头里 | **最像你画的**；静态、不位移 |
| **B 程序化绘制** | `figure.py` 按提取到的色板/画幅/标注惯例画（`make_animation` 那套） | 能动、可逐帧；形状受代码限制 |
| **C 扩散生成** | 本机不具备（缺 SDXL+ControlNet） | 且医学结构不许幻觉 |

现实组合是 **A 出静态解剖底图 + B 出机制动效**，两者共用同一套色板与标注规范 —— 这才叫"统一风格"。

## 4. 「随资料库增加继续升级」怎么实现

这是这条方案里最实的一部分，**不靠模型记忆，靠可重跑的脚本**：

1. 素材放进一个固定目录（例如 `~/.team-agent/illustration-src/`，或你的资料库里）；
2. 每次新增后跑一次 `ingest-illustrations.py`；
3. 它**增量合并**（不是重来）：色板按「**出现在多少张图里**」重新投票
   （⚠️ 这条规则是实测得来的：按像素多少投票会把弹簧圈、微导管的稀有颜色吃掉；
   而按"出现在多少张里"投票能把身份色还原到差 ≤34）；
   术语表去重累加；元件按内容哈希去重；
4. 知识文件写**版本号 + 差异报告**（「本次新增 7 个术语、色板调整 2 项、新增元件 12 个」）；
5. 专家与技能每次都读最新版 → **这就是"升级自己"的全部机制**。

⚠️ 要诚实的一条：**"升级"升的是规范与元件库，不是模型的判断力。** 每加素材，专家能更准地"像你那样画"，
但不会因此更懂神经介入——那部分靠群里已有的医学专家（`cerebrovascular` / `cerebrovascular-public`）把关。
